# fyi-ajah

**The Page, well log.** A super long scroll page: the surface, the strata, 6,371 kilometres of earth in one sitting, and the one resident at the bottom.

Keep scrolling.

## Run it

Fully offline — open `index.html` directly in a browser, or serve the folder:

```sh
npx serve .
```

## Files

| Path | What it is |
|---|---|
| `index.html` | the whole page: 28 sections, the console, the running chips, the receipt |
| `styles.css` | the looks: three-stone palette, field colours per stratum, the type scale |
| `app.js` | the scroll engine: one rAF loop, the depth gauge, the pinned fields |
| `assets/` | strata photographs, the weather clip, the surface stamp |
| `fonts/` | EB Garamond, self-hosted |
| `assets/gorilla.jpg` | the reason for the descent |
